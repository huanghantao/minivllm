# Week 1 本周导读：见证与上手——一个词一个词是怎么蹦出来的

> 本周你将：
> 1. 亲眼看到"同一个模型，换个引擎快 4 倍"的实测证据；
> 2. 把环境装好，让参考答案全绿、你的战场全红——知道终点在哪、起点在哪；
> 3. 学会 PyTorch 的最小生存技能：张量创建、索引、矩阵乘、搬上 GPU；
> 4. 亲手写出第一个生成循环，让 Qwen3-0.6B 一个词一个词地蹦出话来；
> 5. 说清楚"推理引擎到底是干什么的"。

---

## 本周定位

Week 1 是**见证之周**：先别急着懂原理，先看到现象、摸到工具、跑通第一个循环。

这一周你只写两个文件里的十几个小函数（`minivllm/tensor_ops.py` 和
`minivllm/generate.py`），但你会完成三件大事：

1. **见证差距**：同一台 Mac、同一个 Qwen3-0.6B，朴素写法 39.3 token/s，
   真实 vLLM 145.8 token/s——这 4 倍差距就是本课程要填的坑；
2. **热身**：PyTorch 零基础没关系，第 2 章把"张量"讲成数表，逐个函数练手；
3. **跑通自回归**：第 3 章写出 `generate_naive`，先对假模型跑通，再换真实模型说话。

## 学完你会得到什么

- 一台**随时能跑**的实验环境：测试一敲就出结果，真实 vLLM 随叫随到；
- 一份 **PyTorch 生存手册**：后面 7 周用到的每个 torch 操作，都在本周打过底；
- 一个**能说话的生成循环**：虽然笨（每步重算整段），但它真的能让 Qwen3-0.6B 开口；
- 一张**问题清单**：为什么慢？慢在哪？——这些"为什么"就是 Week 3~5 的燃料。

## 常用命令速查

| 命令 | 干什么 |
|---|---|
| `IMPL=reference .venv/bin/pytest tests` | 见证终点：参考答案全绿 |
| `.venv/bin/pytest tests` | 战场现状：你的实现没填，大片红（正常！） |
| `.venv/bin/pytest tests/test_w1.py` | 本周测试：填完第 2、3 章后应该 11 条全绿 |
| `.venv/bin/pytest tests -m "not slow"` | 跳过需要真实权重的慢测试 |
| `HF_HUB_OFFLINE=1 VLLM_METAL_USE_PAGED_ATTENTION=0 ~/codeDir/pythonCode/vllm-metal/.venv-vllm-metal/bin/python hello_vllm.py` | 跑真实 vLLM（第 1 章详解） |
| `make book` | 把教程构建成 HTML 书（输出在 `book/` 目录） |

> ⚠️ 易踩坑：本周所有 `pytest` 命令都要在**仓库根目录**下执行，
> 并用 `.venv/bin/pytest` 而不是全局的 `pytest`——后者没装本项目的依赖。
