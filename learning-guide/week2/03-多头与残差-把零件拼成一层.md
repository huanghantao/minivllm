## 3.1 从"一个词一个向量"到 Q/K/V

上一章我们一直在抽象地谈 Q、K、V。现在落地：模型里每个词先被表示成一个
`hidden_size` 维的向量（默认配置里是 64 维，记作 E）。同一个向量，分别乘三块矩阵，
得到它的 Q、K、V：

```python
self.q_proj = nn.Linear(E, E, bias=False)
self.k_proj = nn.Linear(E, E, bias=False)
self.v_proj = nn.Linear(E, E, bias=False)
self.o_proj = nn.Linear(E, E, bias=False)
```

`nn.Linear(E, E, bias=False)` 一句话解释：**就是一块 (E, E) 的可学习矩阵**，
输入向量右乘它（PyTorch 里是 `y = xWᵀ`），得到新向量。`bias=False` 表示不带
额外的加法项，纯粹一次矩阵乘。

为什么要三块不同的矩阵？回到图书馆类比：同一本书，"贴在外面的标签"（K）和
"正文"（V）用途不同，值得分开加工；"问题清单"（Q）又是第三种加工。三块矩阵就是
三条不同的"加工流水线"，参数在训练中学出来。

还多了一块 `o_proj`：注意力算完之后，把结果**再加工一次**输出。为什么需要它，
讲完多头你就明白了。

## 3.2 多头：一双眼睛不够，就长四双

慢着——如果每个词只用一份 Q/K/V 做一次注意力，那"词与词的关系"就只有**一种看法**。
但语言里的关系是多种多样的：

- "它"回头看"小猫"——这是**指代关系**；
- "小猫"回头看"追着"——这是**主谓关系**；
- "毛线球"回头看"小猫"——这是**所属关系**（谁的毛线球）。

一双眼睛一次只能盯住一种关系。怎么办？**多长几双眼睛，每双各看各的。**

做法朴素得可爱：把 64 维的向量**切成 4 段**，每段 16 维，每一段独立地做一整套
注意力（独立打分、独立 softmax、独立兑 V），最后把 4 段的结果**拼回去**。
每一段就是一个"头"（head）。这就是**多头注意力（multi-head attention）**。

配置里的两个数字管这件事：

```python
self.num_heads = config.num_heads      # H = 4：几双眼睛
self.head_dim = config.head_dim        # D = 64 / 4 = 16：每双眼睛看多少维
```

（`MiniConfig.__init__` 里有一句 `assert hidden_size % num_heads == 0`——
切不均匀就当场报错，省得后面出诡异的形状错误。）

## 3.3 _split_heads / _merge_heads：形状变形记

这两个小工具在 `minivllm/model/transformer.py` 里**已经给出**，不用你写——
但它们是本周最容易晕的地方，必须讲透。

`q_proj(x)` 出来的张量形状是 `(B, L, E)`，也就是 `(几句话, 几个词, 64)`。
而 `scaled_dot_product_attention` 要的是 `(B, H, L, D)`，即 `(几句话, 几个头, 几个词, 16)`。
中间发生了什么？

```python
def _split_heads(self, t):
    """(B, L, H*D) -> (B, H, L, D)：把"人头"维度拆出来。"""
    B, L, _ = t.shape
    return t.view(B, L, self.num_heads, self.head_dim).transpose(1, 2)
```

两步：

1. `t.view(B, L, H, D)`：`view` 是"重新看这块内存"——把最后 64 维**切成** (4, 16)，
   数据一个不动，只是换了"读法"。现在是 `(B, L, H, D)`；
2. `.transpose(1, 2)`：交换第 1、2 维，把"头"挪到"词"前面，得到 `(B, H, L, D)`。

为什么要把 H 挪到前面？因为注意力是**每个头内部独立**算的：`q @ k.transpose(-2, -1)`
只对最后两维（L 和 D）做矩阵乘，前面的 B 和 H 只是"批量编号"。把 H 摆到前面，
等于告诉 PyTorch："这是 B×H 个独立的小注意力，一起算了吧。"

算完注意力，输出还是 `(B, H, L, D)`，用 `_merge_heads` 原路拼回 `(B, L, E)`：

```python
def _merge_heads(self, t):
    """(B, H, L, D) -> (B, L, H*D)：拼回去。"""
    B, H, L, D = t.shape
    return t.transpose(1, 2).reshape(B, L, H * D)
```

> ⚠️ **易踩坑：为什么这里用 `reshape` 而不是 `view`？**
>
> `transpose` 之后张量的内存布局不再连续，`view` 会直接报错；
> `reshape` 更聪明——能省则省，不行就copy一份再变形。记住口诀：
> **transpose/permute 之后想合并维度，用 `reshape`。**

一图胜千言（这是纯形状示意，不涉及坐标）：

```
q_proj 输出:  (B, L, 64)
   │ view(B, L, 4, 16)      ← 把 64 切成 4 段 16
   ▼
              (B, L, 4, 16)
   │ transpose(1, 2)        ← "头"挪到"词"前面
   ▼
              (B, 4, L, 16)  ← 喂给注意力，4 个头各算各的
   │ transpose(1, 2) + reshape
   ▼
              (B, L, 64)     ← 拼回去，交给 o_proj
```

## 3.4 MultiHeadAttention.forward：把前两章焊起来

你要填的 `MultiHeadAttention.forward`，就是把第 1、2 章的东西装进来：

```python
def forward(self, x, past_kv=None):
    """x: (B, L, hidden)。返回 (B, L, hidden)。"""
    q = self._split_heads(self.q_proj(x))
    k = self._split_heads(self.k_proj(x))
    v = self._split_heads(self.v_proj(x))
    if past_kv is not None:
        # 把本次的 K/V 存进仓库，并取出"含历史"的完整 K/V
        k, v = past_kv.append_and_get(self.layer_idx, k, v)
    mask = make_causal_mask(q.shape[2], k.shape[2]).to(x.device)
    out, _ = scaled_dot_product_attention(q, k, v, mask)
    return self.o_proj(self._merge_heads(out))
```

逐行走一遍：

1. 三个投影 + 拆头：`(B, L, E)` → 三个 `(B, H, L, D)`；
2. `past_kv` 这段**本周直接跳过**（调用时它是 `None`，分支不进）——
   这是 Week 3 KV cache 的接口，提前留好。注意它正好解释了上一章的悬念：
   有了缓存，k 的序列长度会大于 q 的，所以下一行造掩码时传的是
   `make_causal_mask(q.shape[2], k.shape[2])`，两个参数可能不相等；
3. 造因果掩码，`.to(x.device)` 把它搬到和模型同一台设备（CPU 或 MPS）；
4. 上一章写的 `scaled_dot_product_attention` 原样调用；
5. 拼回头、过 `o_proj` 输出。

现在 `o_proj` 的意义清楚了：4 个头各看各的，拼起来之后，需要一块矩阵把
"四双眼睛的观察报告"**汇总成一份结论**。它也是可学习的——模型自己学怎么汇总。

## 3.5 MLP：注意力的"消化器官"

注意力负责"词与词之间互通有无"，但每个词拿到的信息还需要**就地消化**一下。
这就是 MLP（前馈网络）：

```python
class MLP(nn.Module):
    def __init__(self, config):
        super().__init__()
        E = config.hidden_size
        self.fc1 = nn.Linear(E, E * config.mlp_ratio)   # 64 -> 256
        self.fc2 = nn.Linear(E * config.mlp_ratio, E)   # 256 -> 64

    def forward(self, x):
        return self.fc2(torch.nn.functional.gelu(self.fc1(x)))
```

结构一句话：**先放大 4 倍，过一道 GELU，再缩回来。**

- 为什么放大？类比头脑风暴：先把想法铺到一个大黑板上（256 维的大空间），
  让各种组合都有地方摆，再收敛回结论（64 维）；
- `torch.nn.functional.gelu` 是激活函数，一句话直觉："**负的压掉、正的保留**"
  的平滑版本——没有它，两层 Linear 叠起来等价于一层，白搭；
- 注意 MLP **不看别的词**：它对每个位置独立作用（逐词消化），
  "互通"全靠注意力。

## 3.6 LayerNorm 与残差：两根保险丝

最后两个零件，都是"工程保险丝"——没有它们模型很难训练，但推理时它们就是
普通的一步计算。各给一句话直觉，不证明。

**LayerNorm（层归一化）**：把每个词的 64 维向量"校准"一下——减去均值、除以波动，
再学一个缩放和平移。类比：**每道菜上桌前先尝一口调咸淡**，防止数值在层与层之间
越滚越大或越滚越小。代码里就是 `nn.LayerNorm(config.hidden_size)`，PyTorch 内置。

**残差连接（residual connection）**：`x = x + attn(ln1(x))`——注意力的输出
**不替换**原来的 x，而是**加到** x 上。类比：编辑改稿子是**在原稿上批注**，
不是把原稿扔了重写。这样哪怕某一层学得不靠谱，原始信息也原样保留，
几十层堆起来信号也不会丢。

## 3.7 DecoderBlock：一层 Transformer 的完整装配

所有零件到齐，装成一层：

```python
class DecoderBlock(nn.Module):
    def __init__(self, config, layer_idx):
        super().__init__()
        self.ln1 = nn.LayerNorm(config.hidden_size)
        self.attn = MultiHeadAttention(config, layer_idx)
        self.ln2 = nn.LayerNorm(config.hidden_size)
        self.mlp = MLP(config)

    def forward(self, x, past_kv=None):
        x = x + self.attn(self.ln1(x), past_kv=past_kv)
        x = x + self.mlp(self.ln2(x))
        return x
```

两行 forward，背下来这个节奏：

1. **先归一化，再注意力，残差加回**（`x + attn(ln(x))`）——词与词互通；
2. **再归一化，再 MLP，残差加回**（`x + mlp(ln(x))`）——每个词就地消化。

（这种"先 LayerNorm 再进子层"的摆法叫 pre-norm，现代模型都这么摆。）

最值得记住的事实：**进一层是 `(B, L, E)`，出来还是 `(B, L, E)`**。形状不变，
残差才能相加，层才能像乐高一样无限堆叠。每个位置的向量经过一层，
就"融合了一遍前文 + 消化了一遍"，层的全部意义就在这。

> 📌 **对标 vLLM：** 打开 `.venv` 里的 `vllm/model_executor/models/qwen3.py`，
> 找到 `Qwen3DecoderLayer`（约 173 行）：`input_layernorm` → `self_attn` →
> 残差 → `post_attention_layernorm` → `mlp` → 残差——和你写的 `DecoderBlock`
> 节奏完全一致。差别只有三处，都是后面周的功课：归一化用的是 RMSNorm（Week 6）、
> MLP 用的是 SwiGLU（Week 6）、注意力带 KV cache（Week 3）。

> 💡 **你可能会问：为什么注意力内部还要分头，直接把 E 维一次性算不行吗？**
>
> 行，那就叫"单头"。但单头只有一套打分方式，等于逼所有关系共用一双眼睛；
> 分头之后每个头可以在自己的小空间里专攻一类模式。实践上多头全面优于单头，
> 代价只是多几次形状变换——计算量几乎一样。

> 📌 **划重点：** 一层 Transformer = `x + attn(ln(x))` 再 `x + mlp(ln(x))`。
> 多头 = 把 E 维切成 H 段各算各的再拼回；LayerNorm 和残差是让深层堆叠
> 不出事的两根保险丝。**形状进去多大、出来多大。**
